08风险与纪律

  • 预算隔离:同 CID 在投 flatkey($41/天),共享账户余额 — 确认余额充足,VOC 用独立 campaign 预算互不挤占。
  • Offer 时效:"limited-time free" 若下线,广告文案要同日跟着改 — 每周一核对官网 offer。
  • 数字口径:每条含数字的文案在物料表内已锚定首页来源;新增文案必须同样锚定。
  • MCP 表述:MCP 已在首页公开("REST, Python SDK, or MCP server"),可以投;但 docs 若未就绪,dev 流量先落首页而非 docs 深链。
